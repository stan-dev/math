Detailed Description

template<ARKODE_ERKTableID Table, bool DenseOutput, typename F, typename T_y0, typename T_t0, typename T_ts, typename... Args>
class stan::math::arkode_integrator< Table, DenseOutput, F, T_y0, T_t0, T_ts, Args >

Integrator interface for ARKODE's ERKStep explicit adaptive Runge-Kutta solver, using one of ERKStep's built-in embedded Butcher tables.

Step size control is configured to match Boost odeint's controlled_runge_kutta, which this integrator replaced.

Template Parameters
TableID of the built-in ERKStep Butcher table to use, e.g. ARKODE_CASH_KARP_6_4_5 or ARKODE_DORMAND_PRINCE_7_4_5
DenseOutputif true output times are interpolated between steps, otherwise steps are truncated to end on each output time
FType of ODE right hand side
T_y0Type of initial state
T_t0Type of scalar of initial time point
T_tsType of time-points where ODE solution is returned
