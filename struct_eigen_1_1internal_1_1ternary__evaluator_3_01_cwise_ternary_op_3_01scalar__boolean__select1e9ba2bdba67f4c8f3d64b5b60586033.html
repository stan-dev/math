Detailed Description

template<typename CondScalar, typename Arg1, typename Arg2, typename Arg3>
struct Eigen::internal::ternary_evaluator< CwiseTernaryOp< scalar_boolean_select_op< stan::math::var, stan::math::var, CondScalar >, Arg1, Arg2, Arg3 >, IndexBased, IndexBased >

Partial specialization of Eigen's ternary evaluator for .select() expressions on matrices of var, restoring the lazy (Eigen 3.x) semantics where only the branch chosen by the condition is evaluated for each coefficient.

Eigen 5's eager evaluator computes both branches, and for var that has the side effect of allocating orphan varis on the autodiff stack; an orphan with a non-finite value whose chain rule multiplies its (zero) adjoint by a value-derived quantity injects 0 * INF = NaN into the adjoints of live inputs. See stan/math/prim/meta/lazy_select_evaluator.hpp for details.

This also covers (a < b).select(c, d) expressions: Eigen's fused comparison-select evaluator derives from ternary_evaluator after rebuilding the expression, so it picks up this specialization.
