Detailed Description

template<typename T, typename CondScalar, typename Arg1, typename Arg2, typename Arg3>
struct Eigen::internal::ternary_evaluator< CwiseTernaryOp< scalar_boolean_select_op< stan::math::fvar< T >, stan::math::fvar< T >, CondScalar >, Arg1, Arg2, Arg3 >, IndexBased, IndexBased >

Partial specialization of Eigen's ternary evaluator for .select() expressions on matrices of fvar<T>, restoring the lazy (Eigen 3.x) semantics where only the branch chosen by the condition is evaluated for each coefficient.

Higher-order autodiff types (e.g. fvar<var>) tape their inner operations, so eagerly evaluating an unselected branch can allocate orphan varis whose chain rules inject 0 * INF = NaN into the adjoints of live inputs. See stan/math/prim/meta/lazy_select_evaluator.hpp for details.
